# Qorgany game art

Characters, boss animations, terrain, effects and interface art from Qorgany, a game about the history of Kazakhstan. The collection includes editable SVGs, PNG frames, sprite sheets, texture atlases and tile maps.

[Browse the artwork releases](https://github.com/Dash-ux/qorgany-game-art/releases). In a release, select **qorgany-game-art.tar.gz** under **Assets**. Extract the archive and open its README. The `gameforhistory/assets` folder contains the art used by the game. The other folders contain the development artwork and earlier versions.
